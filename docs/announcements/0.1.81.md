Drive iOS simulators like real devices with baguette 0.1.81 — taps, gestures, camera, and GPS, all without opening Xcode.

■ WHAT'S NEW

• CAMERA ON CAMERA-LESS MACS — Real camera apps (expo-camera, VisionCamera, AVFoundation) that used to hang on a loading screen now start streaming. No app changes required.

• IMAGE & VIDEO SOURCES — Feed a still image or a looping video straight into the simulator's camera, right beside the live webcam.

• JOYSTICK-DRIVEN LOCATION — Drive the simulator around a map with a thumbstick or WASD controls, with CLLocation.course following your heading. Record a walk and replay it at any speed.

• LOWER-LATENCY H.264 — VideoToolbox low-latency rate control with zero decoder buffering, for noticeably tighter, more responsive interaction.

■ PERFECT FOR

• iOS developers testing camera, QR/barcode, and location flows in the simulator
• QA teams automating UI gestures without launching Xcode
• Anyone pairing Claude Code with a running simulator to verify on-screen state
