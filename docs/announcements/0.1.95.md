# baguette 0.1.95 — Network conditioning

X / social post drafts. Version tagged 0.1.95 (what `brew install` gets today);
the feature itself landed in 0.1.93.

## Option A — recommended

baguette 0.1.95 — drive iOS simulators like real devices.
📶 Network conditioning — make your app see 3G, hotel WiFi, or no signal at all
🎚️ Presets, or your own numbers — add delay, cap the speed, drop requests
⚡ Your Mac stays fast — only the simulator you're testing slows down

brew install tddworks/tap/baguette

## Option B — more concrete

baguette 0.1.95 — drive iOS simulators like real devices.
📶 Network conditioning. Test your app on 3G, Edge, or fully offline
🎚️ Or dial your own — delay, speed cap, % of requests that fail
🔔 Amber dot stays lit so you never forget it's on

brew install tddworks/tap/baguette

## Option C — leads with the pain

baguette 0.1.95 — drive iOS simulators like real devices.
📶 Your app on a bad network, on demand — 3G, spotty WiFi, or offline
🎚️ One preset, or your own delay / speed / failure rate
💻 Per-simulator, not system-wide — the rest of your Mac is untouched

brew install tddworks/tap/baguette

## Notes

- The third bullet is where the options differ most. "Your Mac stays fast" is
  the strongest differentiator for a general audience — hence A.
- Presets borrow Network Link Conditioner's vocabulary *and* its figures:
  `wifi`, `dsl`, `lte`, `3g`, `edge`, `very-bad-network`, `100-loss`.
- Feature docs: [`docs/features/network.md`](../features/network.md).
